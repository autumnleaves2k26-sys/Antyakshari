Build a modern ultra-fast event registration website for an event called “Antyakshari” happening on 31 May 2026.

The website should feel premium, youthful, musical, cinematic, and modern — inspired by indie music festivals and Gen-Z concert aesthetics.

IMPORTANT:
- Keep the tech stack VERY SIMPLE and lightweight.
- Prioritize speed, smoothness, responsiveness, and minimal backend complexity.
- The website should load extremely fast even on mobile devices.
- Use modern typography and clean layouts instead of heavy visuals.
- Use static-first architecture wherever possible.

# TECH STACK

Frontend:
- Next.js 15 (App Router)
- Tailwind CSS
- shadcn/ui
- Framer Motion (minimal animations only)

Backend:
- Supabase
  - PostgreSQL
  - Authentication
  - File uploads/storage

Hosting:
- Vercel optimized

# REGISTRATION SYSTEM

When user clicks “Register Now”:

Show a form asking:
- Full Name
- Email
- Phone Number
- Number of Passes

Dynamic participant system:

If user selects:
1 pass → ask details for 1 participant
2 passes → ask details for 2 participants
etc.

For each participant:
- Participant Name
- Optional Age
- Optional College/Company

Then show:
- Payment QR code
- Payment instructions
- Upload payment screenshot

After submission:
- Save registration as PENDING

# ADMIN DASHBOARD

Create secure admin login.

Dashboard features:
- View registrations
- Approve/reject payments
- Open uploaded payment screenshots
- Generate passes automatically
- Download passes
- Bulk ZIP download

Dashboard UI should be simple and lightweight.

# PASS GENERATION SYSTEM

When admin approves registration:
- Generate unique pass IDs automatically

Example:
- ANT-2026-001
- ANT-2026-002

Generate unique QR code for every pass.

Each pass should contain:
- Event name
- Participant name
- Unique pass ID
- QR code
- Date
- Premium ticket-style design

Pass design should feel like:
- concert ticket
- music festival pass
- premium event invite

# QR VALIDATION SYSTEM

Create QR scanner/validation page.

When scanned:
- Show VALID / USED / INVALID
- Mark pass as USED after first scan
- Prevent duplicate entry

# BULK DOWNLOAD FEATURE

Admin should be able to:
- Download all passes at once
- Automatically generate ZIP file
